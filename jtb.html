📘 JTB TIN Verification API Documentation

🔐 Authentication & Access

To use the TIN Verification API, you must obtain:

  • A valid API token
  • Your IP address whitelisted

📧 To request access, send an email to: Admin@jtb.oyostate.gov.ng

Include your:

  • Organization name
  • Intended use
  • Public IP address to be whitelisted

🚀 API Endpoint

POST /api/v1/verify-tin

Base URL:

https://jtb.oyostate.gov.ng/api/v1/verify-tin

🔐 Headers

KeyValue
AuthorizationBearer {your_api_token}
Content-Typeapplication/json

📥 Request Payload

FieldTypeRequiredDescription
typestring✅Either individual or non-individual
tinstring✅The 10-digit TIN number

📦 Example Requests

Individual

curl -X POST https://jtb.oyostate.gov.ng/api/v1/verify-tin ^
  -H "Authorization:Bearer {your_api_token}" ^
  -H "Content-Type:application/json" ^
  -d "{\"type\":\"individual\",\"tin\":\"1203333768\"}"

Non-Individual

curl -X POST https://jtb.oyostate.gov.ng/api/v1/verify-tin ^
  -H "Authorization:Bearer {your_api_token}" ^
  -H "Content-Type:application/json" ^
  -d "{\"type\":\"non-individual\",\"tin\":\"0025151925\"}"
